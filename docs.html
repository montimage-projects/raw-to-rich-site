Install

r2r needs Python 3.12, 3.13 or 3.14. Install it from source in a virtual environment; this puts the r2r command on your path.

git clone https://github.com/montimage-projects/raw-to-rich.git
cd raw-to-rich
python -m venv .venv && source .venv/bin/activate
pip install -e .

Every command also works without installing the entry point, as python -m src <command> from the repository root.

Basic usage

process is the main command. Given a data file and a template, it renders a prompt for every row, sends it to the configured provider, filters the responses and writes JSONL.

# 1. check the data against a template
r2r process data.csv --validate --template qa

# 2. look at five real responses before a full run
r2r process data.csv --preview --samples 5 --config config/ollama.yaml

# 3. generate the dataset
r2r process data.csv --config config/ollama.yaml --output dataset.jsonl

Each output line holds one conversation in the format Unsloth loads:

{"conversations": [
  {"from": "human", "value": "<rendered prompt>"},
  {"from": "gpt",   "value": "<model response>"}
]}

A system turn is added first when the template defines a system message.

Examples

Common workflows:

  Generate instruction dataset (default):
r2r process data.csv --output dataset.jsonl
r2r process data.csv -g -t qa -o out.jsonl

  Preview samples:
r2r process data.csv --preview --samples 5
r2r process data.csv -p -n 5

  Balance dataset:
r2r process data.csv --balance --samples 100 --output balanced.csv
r2r process data.csv -b -n 100 -o balanced.csv

  Clean data:
r2r process data.csv --clean --output cleaned.csv
r2r process data.csv -c -o cleaned.csv

  Validate data:
r2r process data.csv --validate --template qa
r2r process data.csv -V -t qa

Tracing

LangSmith tracing is off by default (langsmith.enabled: false in config/base.yaml). When you enable it and set LANGSMITH_API_KEY, prompts and responses are sent to the configured LangSmith endpoint under the project rawtorrich.
