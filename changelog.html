1.1.0 2026-01-17 Latest

Changed

Breaking Changes

  • Package renamed: instruction-data-generator → r2r
  • Product rebrand: Now known as "RawToRich"
  • CLI command: New r2r command (e.g., r2r process data.csv)
    • Backward compatible: python -m src still works
  • LangSmith project: instruction-data-generator → rawtorrich

Migration Guide

If you previously installed:

pip uninstall instruction-data-generator
pip install r2r

Update your scripts:

# OLD
python -m src.cli generate --input data.csv --output out.jsonl

# NEW (preferred)
r2r process data.csv --output out.jsonl

# STILL WORKS (backward compatible)
python -m src process data.csv --output out.jsonl

Update environment variables:

# OLD
LANGSMITH_PROJECT=instruction-data-generator

# NEW
LANGSMITH_PROJECT=rawtorrich

Documentation

  • Updated all documentation to reflect RawToRich branding
  • Updated CLI examples to use r2r command as primary
  • Maintained GitHub repository URL for backward compatibility
  • Added migration guide for upgrading from v1.0.0
