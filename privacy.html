Privacy

Summary

The website sets no cookies, runs no analytics and has no forms. The r2r tool runs on your machine and sends nothing to Montimage. Your data goes only to the LLM provider you configure, plus LangSmith if you turn tracing on.

Who we are

This website and the r2r tool are published by Montimage. For any privacy question or request, write to contact@montimage.eu.

This website

This site is a set of static pages. It has no accounts, forms, cookies, analytics or advertising, and it stores nothing in your browser.

Hosting

The site is hosted on GitHub Pages. When you load a page, GitHub receives standard request data, such as your IP address, browser and the page requested, and may log it for security and operations. See the GitHub General Privacy Statement.

Fonts

Pages load the Inter and JetBrains Mono fonts from Google Fonts. Your browser therefore requests them from Google's servers, which receive your IP address and browser details. See the Google Privacy Policy. Block those requests and the pages still work, using your system fonts.

The r2r tool

r2r is software you install and run yourself. It contains no telemetry, usage reporting or update checks, and it sends nothing to Montimage.

LLM providers you choose

To generate a dataset, r2r renders a prompt from each row of your input and sends it to the provider in your configuration:

  • Ollama runs on your own hardware, so prompts and responses stay on your machine or network.
  • Cloud providers (OpenAI, Anthropic, Google Gemini, Mistral, OpenRouter, Perplexity) receive each prompt under your own API key. How they process it is governed by your agreement with that provider.

Don't send personal or confidential data to a cloud provider unless your agreement with it allows that.

API keys

r2r reads API keys only from environment variables. A key written into a YAML config file is ignored. Keys are passed to the matching provider and nowhere else.

Optional LangSmith tracing

Tracing is off by default. If you enable it and provide a LangSmith key, r2r sends run traces, including prompts and responses, to the LangSmith endpoint in your configuration, under your LangSmith account.

Your files

Input data, generated datasets and reports are read from and written to paths you choose on your machine.

If you contact us

If you email Montimage, we use your address and message to reply, and keep the correspondence only as long as needed to handle your request.

Your rights

If you are in the European Union or the European Economic Area, the GDPR gives you the right to access, correct or delete personal data we hold about you, to object to or restrict its processing, and to complain to your data protection authority. To exercise these rights, write to contact@montimage.eu.

Changes to this policy

We update this page when the website or the tool changes how data is handled. The date at the top shows the latest revision. Earlier versions are in the site's public repository history.
